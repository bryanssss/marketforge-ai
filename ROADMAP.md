# Roadmap

## 0.4 — Evaluation Lab

- Calibration curves and horizon-by-horizon error charts.
- Frozen benchmark manifests and data hashes.
- Statistical comparison tests and confidence intervals.
- Browser end-to-end tests.
- Docker build and smoke test in CI.

## 0.4 — Portfolio Simulator

- Event-driven cash and position ledger.
- Multiple assets and capital reservation.
- Exposure, leverage and correlation limits.
- Split/dividend and market-session handling.

## 0.5 — Model Registry

- Immutable model revisions and local weight hashes.
- Experiment database and result comparison.
- Optional batch Kronos evaluation.
- Verified training-cut-off metadata when available.

## Later Research

- Multi-timeframe inputs.
- Regime-conditioned ensembles.
- Licensed order-book and derivatives features.
- An independently trained MarketForge tokenizer/model only after benchmark infrastructure is complete.
