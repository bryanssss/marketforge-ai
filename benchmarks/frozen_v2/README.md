# Prospective Frozen Benchmark v2

This is the official MarketForge prospective protocol. It supersedes v1 before the holdout starts because the final audit found that `device: auto` could select different numerical hardware.

V2 pins CPU execution, one numerical thread, deterministic algorithms, Python/package versions, exact 00:00 UTC forecast origins, provider archive hashes, canonical data hashes, model/source revisions, and an append-only prediction ledger.

The holdout remains 1 August through 31 October 2026. Data collection is intentionally blocked until 3 November 2026.
